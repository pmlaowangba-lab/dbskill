## 〇、全盘资产图

```
                  AI 带货视频生成工具站（主产品）
                          ↑
                      （核心资产）

   抖音/小红书主号  +  矩阵号 ×3     +  公众号
   (吸粉 + 人设)    (吸粉 + 走量)    (成交 + 沉淀)
        ↓              ↓                ↓
                    私域微信群
              (工具用户 + 课程学员混合社群)
                          ↓
                  ┌───────┴───────┐
                  ↓               ↓
            工具订阅 ¥99/月    AI 编程课 ¥1999
              (高频复购)        (一次性高客单)
```

**核心原理**：
- 短视频 = 公域获客
- 公众号 = 半私域成交
- 微信群 = 完全私域复购
- 工具 = 高频低客单（带新人入门）
- 课程 = 低频高客单（深度变现）

## 一、起步前必须先完成（Day 0）

不做完不要开始发内容，否则会重蹈 DB 原子里"自媒体必死梦幻开局"的覆辙。

### 1.1 产品最小可售形态

| 项目 | 配置 | 价格 |
|---|---|---|
| 工具免费版 | 每月 3 条视频生成 | ¥0 |
| 工具引流款 | 一个月会员 + 30 条 | ¥9.9 |
| 工具利润款 | 月度无限生成 | ¥99/月 |
| 工具年卡 | 年付 + 优先客服 | ¥299/年 |
| 课程预售 | AI 编程课 ¥1999 → 预售定金 | ¥199 锁名额 |

**DB 公理**："如果你不能把付款链接发给我让我支付成功，你就是没有产品。" 所有支付链接必须能跑通才能发第一条视频。

### 1.2 三个号注册到位

| 号 | 平台 | 定位 | 头像/名字 |
|---|---|---|---|
| 主号 | 抖音 + 小红书 | 创始人 IP（出镜） | 真人 + 真名/花名 |
| 矩阵号 ×3 | 抖音/小红书 | 工具演示（不出镜） | 数字账号名（带类目：女装版/美妆版/食品版） |
| 公众号 | 微信 | 成交 + 沉淀 | 与主号同名 |

矩阵号注册：手机蜂窝网络下注册，避免同 IP 关联。一人最多 5 个公众号，订阅号助手 App 直接注册不实名（DB 原子 2024Q4_482）。

### 1.3 公众号基建（最重要）

**菜单栏（固定 3 个一级菜单）**：
```
[ 体验工具 ]   [ 加入课程 ]   [ 找到我 ]
  ├ 免费试用      ├ 课程详情     ├ 加微信
  ├ 月卡 ¥9.9    ├ 学员战报     ├ 进社群
  └ 年卡 ¥299    └ 预售名额     └ 创始人故事
```

**关键字自动回复**（必配 6 个）：

| 用户发 | 公众号回 |
|---|---|
| 工具 / 试用 / 生成 | 工具链接 + 9.9 月卡卡片 + "回复'案例'看真实战报" |
| 课程 / 学 / AI编程 | 课程详情 + 预售优惠 + "回复'故事'看我怎么做出工具的" |
| 案例 / 战报 | 3 个真实用户案例 + "回复'群'加入用户社群" |
| 群 / 进群 / 微信 | 个人微信二维码 + "备注'公众号'通过更快" |

| 脚本 / 资料 | 200 条带货脚本资料包（涨粉钩子） |

**关注后自动回复**（首条欢迎语）：

## 七、关键指标 & 复盘节奏

### 7.1 每周看一次的核心指标

| 渠道 | 看什么 | 红线 |
|---|---|---|
| 主号 | 完播率（必须 >60%） | 一个月 30% 视频未过 60% → 内容方向有问题 |
| 矩阵号 | 单条点击工具链接数 | 单号一周 <10 次点击 → 换内容方向 |
| 公众号 | 关注数 + 关键字回复触发数 | 周关注 <20 → 涨粉钩子失效 |
| 私域 | 入群人数 + 群活跃度 | 周入群 <10 → 公众号 CTA 失效 |
| 工具站 | 9.9 月卡转化率 | <2% → 引流款定价/承接有问题 |
| 课程预售 | 周成交单数 | <2 单 → 课程价值主张不清 |

### 7.2 每月一次大复盘（DB 提到的"必死工作法"）

每月最后一个周日，强制做：
1. 把这个月所有视频按点赞降序排
2. 前 5 条找共同点 → 下个月按这个公式做
3. 后 5 条找共同点 → 下个月禁止做
4. 公众号阅读量前 3 文章 → 拆成短视频再发一遍
5. 工具用户访谈 3 个 → 找下个月内容选题

## 八、6 个必须避的坑（DB 原子警告）

1. **不要靠一条爆款确定模式** —— "自媒体必死梦幻开局：随手发爆款 → 赶紧变现 → 后续爆款消失收入归零"
2. **不要做"AI 教程号"** —— 高收藏低转化，被算法打成"工具人"标签
3. **不要把工具做得太"专业"** —— 小白不会用提示词，半天卖 3-5k 的计划会卖到几十份
4. **不要在公众号写"产品经理周报"** —— "起调太高读者寥寥"
5. **不要矩阵号完全自动化** —— "算法识别出像机器人就限流"
6. **不要把内容本身当变现产品** —— "把内容本身作为变现产品是效率最差的变现手段"

## 附录 B：商标 / 合规 / 资质准备清单

> 核心判断：**商标和软著建议做，专利绝大多数情况下不用做。但有几样比这些更紧急——大部分人忽略的"业务能跑通"的合规前提。**

### B.1 必须先做（不做开不起来）

| 项 | 为什么 | 成本 | 时间 |
|---|---|---|---|
| **个体户/公司营业执照** | 没有就收不到大额支付、开不了发票、平台不让长期带货 | 个体户 ¥0（自跑）/ ¥500（代办）<br>公司 ¥1000-3000（代办） | 1-7 天 |
| **对公账户 + 支付通道** | 收款超过一定金额，个人微信/支付宝会被风控冻结 | 银行开户 ¥500-2000 | 3-7 天 |
| **域名 ICP 备案** | 工具站如果服务大陆用户，**法律强制**，未备案的站会被封 | ¥0（自跑） | 7-20 个工作日 |
| **公众号认证** | 不认证：菜单栏受限、关键字回复 5 个上限、无原创、无小程序 | ¥300/年（腾讯收） | 7 天 |

⚠️ **关键提醒**：ICP 备案现在卡得严，**需要先有营业执照才能备案**，链路最长。今天就开始走。

---

### B.2 建议早做（成本低、防风险高）

#### 商标 ⭐⭐⭐⭐ 强烈建议

**做的理由**：
- 一旦工具/课起量，**80% 概率被抢注**——专门盯小开发者，做大了来勒索（赎回价 5w-50w）
- 一旦被抢注，公众号名、视频号名、抖音名都可能被强制改
- 中国是"申请在先原则"，谁先注册谁拥有，不看谁先使用

**怎么做**：
1. 先到 [中国商标网](https://sbj.cnipa.gov.cn) 查重（免费）
2. 至少注册三类：
   - **第 9 类**（软件/SaaS）
   - **第 41 类**（教育培训/在线课程）
   - **第 42 类**（SaaS 服务平台）
3. 每类 ¥300 官费 + 代理费 ¥500-1000，**三类合计 ¥3000 左右**
4. 周期：9-12 个月下证，**申请号当天就能拿到**（产品页可挂"商标申请中"）

**做的时机**：在公开发第一条视频之前。内容铺开后，被抢注的窗口就开始计时。

#### 软著 ⭐⭐⭐ 选做

**做的理由**：
- 便宜（¥0 自跑 / 加急代办 ¥800-1500）
- 周期快（普通 30-60 天，加急 1-3 天）
- 用途：App 上架、B 端招投标、申请"双软认证 / 高新技术企业"减税、版权纠纷举证

**不做的理由**：
- 法律效力比商标弱很多——只证明"代码是你写的"，**不能阻止别人写一个一模一样功能的产品**
- 早期个人开发者卖 SaaS 订阅几乎用不到

**做的时机**：月流水稳过 ¥1w，或要上微信小程序/App 商店时。

#### 内容合规（最容易被忽略）⭐⭐⭐⭐

| 项 | 触发条件 |
|---|---|
| **不能写"最""第一""唯一"** | 广告法禁止极限词，被举报 ¥20w 起罚 |
| **课程不能承诺"包就业""保收入"** | 教培广告法红线 |
| **AI 生成内容必须标注** | 2023 起规定，深度合成内容需明确标识 |
| **公众号不写医疗/金融/政治敏感词** | 容易封号 |

**实操**：所有文案过一遍 `广告法极限词查询工具`（搜索可得，免费），10 秒搞定。

---

### B.3 别做或晚做（性价比极低）

#### 专利 ❌ 不建议

- **AI 工具 99% 申请不下来**：套壳大模型 API 没有"独创性技术方案"
- **发明专利成本**：¥5000-2w，周期 2-3 年，下证率 < 30%
- **就算下证**：竞争对手稍微改一下实现就绕开了，对个人开发者保护意义极弱

**例外**：如果你的工具里**真有一个独创的技术方案**（不是提示词，而是某个算法/架构），可以考虑。这种情况你自己最清楚。

#### "高新技术企业""双软认证" ❌ 暂时不要

- 适合年营收 500w+ 的公司
- 申请要审计、专利、研发费用归集、人员社保等一堆材料
- 投入 ¥3-10w，目的是减税
- 早期还在亏钱，没税可减

### B.4 按起号阶段的执行节奏

#### 0-30 天（起号期）必做：
1. 注册个体户营业执照（或挂靠朋友公司开发票）
2. 公众号认证（¥300）
3. 商标查重 + 申请第 9、41、42 类（¥3000）
4. 域名 ICP 备案（免费，等 15 天）

#### 30-90 天（收入跑通）再做：
5. 软著申请（如果上小程序/App）
6. 申请专版微信支付商户号（不再用个人收款码）

#### 月入 5w+ 再考虑：
7. 注册有限责任公司（个体户不利于扩大）
8. 内容合规法务审一遍课程页和工具页

### B.5 与 DB 方法论的对接

DB 反复强调："**先跑通收钱，再补合规。**"
- 原子核心："如果你不能把付款链接发给我让我支付成功，你就是没有产品"
- 翻译：**别让法律前置准备拖死执行力**

但**商标是唯一例外**：
- 不影响今天卖货
- 但等卖起来再做就来不及（被抢注就完蛋）

**所以推荐节奏**：
1. **今天**：商标查重 + ICP 备案 + 个体户注册（三件并行）
2. **本周**：三件落地 + 公众号认证补上
3. **照常**：按正文 4 周 SOP 发内容、跑销售
4. **3 个月后**：根据收入决定是否升级公司、加软著
